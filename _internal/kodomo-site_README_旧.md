# こども道具研究所 — 統合サイト一式

会社紹介サイトと、年齢別ギフト特集ページを1つにまとめたサイトです。
ギフト特集の商品は、microCMS（管理画面）から編集できるようにしてあります。

## フォルダ構成

```
kodomo-site/
├─ index.html            ← 会社紹介（トップ）
├─ gift.html             ← 年齢別ギフト特集（microCMS接続）
├─ assets/               ← 会社紹介サイト用の画像を入れる
├─ microCMS接続ガイド.md  ← ★商品を管理画面で編集する手順（重要）
└─ README.md             ← このファイル
```

ヘッダーのナビで、会社紹介 ⇄ ギフト特集 を行き来できます。

## 2つのサイトのつながり

- `index.html`（会社紹介）のナビに「ギフト特集」リンクを追加 → `gift.html` へ。
- `gift.html`（ギフト特集）のロゴ・ナビから `index.html` へ戻れます。

## いますぐできること

- そのままブラウザで開けば、**サンプル商品**でギフト特集が動きます
  （年齢・予算ボタンで実際に絞り込めます）。
- microCMSを設定すると、商品が管理画面の内容に切り替わります。

## 商品を管理画面で編集できるようにする（本命）

`microCMS接続ガイド.md` に沿って進めてください。要点は次の通り：

1. microCMSに無料登録し、サービスを作成
2. `products` という「商品API」を作り、フィールド（name / price / age / image / rank）を定義
3. 商品を登録
4. APIキーを取得
5. `gift.html` の「★ microCMS 接続設定 ★」に サービスID と APIキー を入力

これで、以降は**コードを触らずに管理画面から商品を増やせます**。

## 公開する

フォルダごと無料ホスティングにアップします。
- **Netlify Drop** … https://app.netlify.com/drop にドラッグ＆ドロップ
- Cloudflare Pages / Vercel / GitHub Pages も可（いずれも無料・https付き）

## 注意（実運用時）

- 商品名・価格はダミー（サンプル）です。実データに差し替えてください。
- APIキーはフロントに出るため、読み取り専用の公開データのみ扱ってください。
  より安全な構成（ビルド時埋め込み）にしたい場合は対応できます。
- 実販売には「特定商取引法に基づく表示」ページが必須です（フッターに枠あり）。
