# microCMS 接続ガイド（商品を管理画面で編集できるようにする）

このサイトの商品一覧を、microCMSの管理画面から追加・編集できるようにする手順です。
※ 設定を入れる前でも、サイトはサンプル商品を表示するので壊れません。安心して進めてください。

────────────────────────────────
STEP 1｜microCMSに登録して「サービス」を作る
────────────────────────────────
1. https://microcms.io/ にアクセスし、無料（Hobbyプラン）で登録。
2. 「サービス」を新規作成。サービスIDを決めます（例: kodomo-toys）。
   → このIDが管理画面URL https://kodomo-toys.microcms.io の一部になります。
   → あとで gift.html に入力するので控えておきます。

────────────────────────────────
STEP 2｜「商品」APIを作る（＝データの入れ物を定義）
────────────────────────────────
1. 「APIを作成」→ 自分で決める（またはブログテンプレートを空にする）。
2. エンドポイントは  products  にする（gift.htmlの初期設定と揃うのでラク）。
3. APIの型は「リスト形式」を選ぶ。
4. 下記の「フィールド」を追加する（フィールドID＝英数字が重要。表示名は自由）：

   ┌─────────────┬──────────────┬────────────────────────────┐
   │ フィールドID │ 種類          │ 説明                        │
   ├─────────────┼──────────────┼────────────────────────────┤
   │ name        │ テキスト      │ 商品名                      │
   │ price       │ 数字          │ 税込価格（数字のみ。例 1800）│
   │ age         │ セレクト      │ 対象年齢（下の選択肢を登録） │
   │ image       │ 画像          │ 商品写真（正方形推奨）       │
   │ rank        │ 数字          │ 表示順・順位（任意）         │
   └─────────────┴──────────────┴────────────────────────────┘

   ★ age（セレクト）の選択肢は、次の11個を “そのままの文字で” 登録してください。
      文字が違うと絞り込みが効きません。
      0ヶ月〜 / 3ヶ月〜 / 6ヶ月〜 / 10ヶ月〜 / 1歳〜 / 1歳半〜 /
      2歳〜 / 3歳〜 / 4歳〜 / 5歳〜 / 6歳〜
      （「選択できる数」は 1個 に設定するのがおすすめ）

────────────────────────────────
STEP 3｜商品を1つ登録してみる
────────────────────────────────
1. 「コンテンツ」→「追加」。
2. name・price・age・image を入れて「公開」。
   まず1〜2件でOK。表示を確認してから増やせます。

────────────────────────────────
STEP 4｜APIキーを取得する
────────────────────────────────
1. 左メニュー「権限管理」→「APIキー」。
2. 既定のキー（GET権限があるもの）をコピー。
   ※ 迷ったら、デフォルトのキーでGETが許可されていればそのままでOK。

────────────────────────────────
STEP 5｜gift.html に2か所を入力する
────────────────────────────────
gift.html を開き、上のほうにある「★ microCMS 接続設定 ★」の部分を書き換えます。

  変更前：
    serviceDomain: "ここにサービスID",
    apiKey:        "ここにAPIキー",

  変更後（例）：
    serviceDomain: "kodomo-toys",
    apiKey:        "abcd1234...(コピーしたキー)",

保存してブラウザで開き直すと、商品一覧が「microCMSの中身」に切り替わります。
画面上部に「microCMSと接続中」と表示されれば成功です。

────────────────────────────────
⚠ 大切な注意（セキュリティと制限）
────────────────────────────────
・この方法では、APIキーがブラウザから見える状態になります。
  公開してよい「商品情報の読み取り専用（GET）」であれば実用上は許容されますが、
  在庫や個人情報など“見せたくないデータ”はこの方式では扱わないでください。
・より安全にしたい場合の王道は「ビルド時にデータを埋め込む（SSG）」方式です。
  NetlifyやCloudflare Pagesと組み合わせると実現できます（次のステップで対応可能）。
・無料プランは月20GBの転送量制限、動画・PDFのアップロード不可。
  商品画像（JPG/PNG）は問題なく使えます。

────────────────────────────────
つまずいたら
────────────────────────────────
・「接続に失敗しました」と出る → サービスID・APIキー・エンドポイント名(products)を確認。
・商品が0件 → microCMSでコンテンツを「公開」状態にしているか確認。
・年齢で絞り込めない → age の選択肢の文字が、上のリストと一字一句同じか確認。
  画面のスクリーンショットを Claude に渡せば、一緒に原因を探します。
